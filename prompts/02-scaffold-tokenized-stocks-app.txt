## Architecture

```text
Browser :3000  →  backend :3001  →  clob-index :3002  →  lightpool node
```

- Backend is a **client of clob-index**, not of node RPC `:26300`.
- Frontend talks only to the backend (`NEXT_PUBLIC_API_URL=http://127.0.0.1:3001/api`).
- Types: `Address` = user (20-byte); `ContractAddress` = token/spot market (8-byte, often `0x02…` / `0x03…`). Do not mix them.

## Backend requirements

Stack: Rust 2021, Axum, tokio, tower-http (CORS + trace), serde, dotenvy, reqwest, tracing.

Binary name: `tokenized-stocks-backend`.

Env (`.env.example` + `.env`):

```text
HOST=0.0.0.0
PORT=3001
CLOB_INDEX_URL=http://127.0.0.1:3002
```

Routes (all under `/api`):

| Method | Path | Behavior |
|--------|------|----------|
| GET | `/api/health` | `{ "status": "ok" }` |
| GET | `/api/ready` | GET `{CLOB_INDEX_URL}/api/health/health`; if ok return `{ "status": "ready", "clob_index": true }`, else `{ "status": "degraded", "clob_index": false }` (still HTTP 200) |

CORS: allow localhost frontend origin.

Do **not** add lightpool-sdk, place-order, DB, JWT, or bridge in this scaffold.
Do **not** invent other clob-index routes here.

Optional: if sibling `lightpool-sdk-rust` exists, you may note in README that later chapters will depend on it via path `../lightpool-sdk-rust` — but do not wire it yet.

## Frontend requirements

Stack: Next.js (App Router) + TypeScript.

- One simple home page: title `Tokenized Stocks`, one line that this is a LightPool spot-exchange sample, and show backend health by fetching `/api/health` (via `NEXT_PUBLIC_API_URL`).
- `.env.example` / `.env.local`:

```text
NEXT_PUBLIC_API_URL=http://127.0.0.1:3001/api
```

- No trade UI panels, no wallet connect, no chart library yet.
