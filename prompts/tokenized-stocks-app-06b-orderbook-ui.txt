## Goal

In `lightpool-labs/tokenized-stocks-app/frontend/`:

1. Replace the `OrderBookPanel` placeholder with a live order book for the **selected** LightPool spot market.
2. Load a **full book snapshot** from clob-index, then **subscribe** to `orderbook_delta` for updates.
3. Frontend talks **directly to clob-index** (`:3002`), not via the app backend, and not to Hyperliquid for this panel.

## Data path

```text
Selected market.spot_market (ContractAddress 0x03…)
    → GET  http://127.0.0.1:3002/api/spot/{spot_market}/book?depth=…
    → WS   ws://127.0.0.1:3002/api/ws  channel=orderbook_delta
    → OrderBookPanel (asks / mid / bids)
```

- `spot_market` comes from chapter 4 registry / selected market state.
- Encode the address in the HTTP path (`encodeURIComponent`).
- Depth: default `10` or `20` (index clamps 1…50).

Contrast with chart (chapter 5): chart uses Hyperliquid `xyz:SYMBOL` via backend; **order book uses LightPool clob-index only**.

## Implement (follow orderbook-client.md)

1. Add a small client module (e.g. `frontend/lib/orderbook.ts`) with:
   - `fetchBookSnapshot(spotMarket, depth)`
   - `applyOrderBookDelta(...)`
   - `subscribeOrderBook(spotMarket, depth, { onBook, onError })` → returns unsubscribe
2. Wire `OrderBookPanel` (and `TradeShell` if needed) to the selected market:
   - On select / change: unsubscribe previous → clear → snapshot → subscribe
   - On snapshot message: replace book
   - On delta: merge (`size` `"0"` removes level)
   - Optional: `requestAnimationFrame` throttle before setState
3. UI: asks above, mid / last trade, bids below (price, size; optional total). Empty state when no market or empty book.
4. Env (frontend `.env.example`):

```text
NEXT_PUBLIC_CLOB_INDEX_URL=http://127.0.0.1:3002
NEXT_PUBLIC_CLOB_INDEX_WS_URL=ws://127.0.0.1:3002
```
