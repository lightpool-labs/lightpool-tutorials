## Required layout (must match)

```text
┌────────────────────────────────────────────────────────────┬──────────────────┐
│ Top bar: logo | Trade | Admin | wallet / connect           │                  │
├──────────┬──────────────────────┬──────────────────────────┤  Order ticket    │
│ Markets  │  Chart (bars)        │  Order book              │  buy / sell      │
│ list     │                      │  + recent trades         │                  │
│          │                      │                          │  Deposit /       │
│          │                      │                          │  Withdraw        │
├──────────┴──────────────────────┴──────────────────────────┤                  │
│ Bottom tabs: Balances | Open orders | History | Fills      │                  │
└────────────────────────────────────────────────────────────┴──────────────────┘
```

Hard geometry rules:

1. Left-to-right: **Markets | Chart (bars) | Order book (+ recent trades) | Order ticket**.
2. **Order ticket** is a **full-height right column** (buy/sell on top, Deposit / Withdraw under it).
3. **Bottom tabs** span only to the **right edge of the order book**; they must **not** sit under the order ticket.
4. Top bar spans the area above Markets + Chart + Order book (not necessarily over the order ticket column). Links: logo, Trade, Admin, wallet / connect placeholder.

## Frontend requirements

Stack: keep Next.js App Router + TypeScript. Prefer simple CSS (CSS modules or `globals.css`); no need for a heavy UI kit.

### Trade page (`/` or `/trade`)

Placeholder panels (static fake labels OK, e.g. market name `AAPL/USDT`):

| Panel | Placeholder content |
|-------|---------------------|
| Markets list | Fake rows (e.g. AAPL/USDT, TSLA/USDT); clicking may set local selected label only |
| Chart (bars) | Box titled Chart / bars; empty or “Chart placeholder” |
| Order book | Asks / bids empty tables + “Recent trades” empty list |
| Order ticket | Buy / Sell toggle or tabs; size/price inputs disabled or non-functional; Submit button does nothing useful |
| Deposit / Withdraw | Under order ticket: two buttons or mini form, non-functional |
| Bottom tabs | Tab headers: Balances, Open orders, History, Fills; empty table body per tab |

User must be able to **click around** the shell (switch bottom tabs, select a fake market name, switch Buy/Sell) without backend errors.

### Admin page (`/admin`)

Separate empty page reachable from top bar **Admin**:

- Title Admin
- Placeholder sections: Create token, Create spot market, Mint / fund
- No real CLI or API calls

### Optional

- A stub `/liquidity` or note in Admin that liquidity maker is later — not required as a full page.
- Keep a small backend health indicator somewhere discreet (e.g. top bar) using existing `/api/health` — optional.

## Do not do in this step

- Do not implement Admin create-token / create-market for real
- Do not start `lightpool-node` / indexer / bots
- Do not add unit tests unless asked
